# 🎬 Animaciones en Python para YouTube

Colección de scripts en Python desarrollados con [Manim](https://www.manim.community/) para la creación de animaciones matemáticas y científicas publicadas en YouTube.

---

## 🛠️ Requisitos Previos

En **Linux (Ubuntu/Debian/Linux Mint)**, instala las dependencias del sistema necesarias para renderizar video y texto:

```bash
sudo apt update
sudo apt install -y python3-pip python3-venv ffmpeg texlive-full libcairo2-dev
